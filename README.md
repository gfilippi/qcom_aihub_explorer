# qcom_aihub_explorer

An offline explorer of Qualcomm AI Hub model performance. For each upstream release of
[qualcomm/ai-hub-models](https://github.com/qualcomm/ai-hub-models), it builds a
self-contained HTML snapshot that maps every published model on an efficiency chart:
on-device speed against accuracy. The chart can be filtered by platform, device, task,
runtime and precision, has popups with model details and links to the
[AI Hub](https://aihub.qualcomm.com/models) model pages, and has a dedicated LLM view.
Keeping one snapshot per release makes it possible to compare models across
AI Hub / QAIRT versions.

The code that collects the data and generates the pages has its own documentation
(architecture, data model, usage) in [src/README.md](src/README.md).
