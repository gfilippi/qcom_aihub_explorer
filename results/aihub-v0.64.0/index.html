About this snapshot

  • Data: qualcomm/ai-hub-models v0.64.0 (commit 53af617346, 2026-10-06), BSD-3-Clause. Generated 2026-10-17. Unofficial offline view; numbers are as published upstream.
  • Tool versions in this release: onnx_runtime 1.27.1, 1.30.0; qairt 2.45.0.260326154327, 2.50.0.260828221209.
  • Accuracy is measured upstream on a single device per model (shown in each popup); it does not change with the selected device. Only latency / throughput does.
  • Default Y value is the quantized on-device accuracy. "Float" uses the float on-device accuracy, falling back to the PyTorch reference when no on-device value exists.
  • Models split into several components (e.g. encoder + decoder) are plotted with the sum of their component latencies.
  • Devices marked * have no measurements of their own: AI Hub copies the numbers of a similar chipset onto them.
